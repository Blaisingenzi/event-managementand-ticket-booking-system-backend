How to Run

1. Make sure you have Java, Maven and PostgreSQL installed
2. Create a database called event_management_db in PostgreSQL
3. Open the file src/main/resources/application.properties and set your PostgreSQL username and password
4. Run the project with this command:

mvn spring-boot:run

5. The API will start at http://localhost:8080


How to Test

Open Postman
Import the file event-managementand-ticket-booking-system-midterm.postman_collection.json
Run the requests
